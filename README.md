# JobParser — сбор и аналитика IT-вакансий

## Запуск
Требуется .NET 8 SDK.
```bash
dotnet restore
dotnet run
```

## Разделы
- **Вакансии** — запуск парсеров, фильтрация и экспорт CSV.
- **Аналитика** — диаграммы по профессиям, компаниям, зарплатам и регионам. Журнал хранит до 500 последних запусков.
- **Журнал** — логи запусков парсеров, при наличии ошибки выводит ее также в логи.
